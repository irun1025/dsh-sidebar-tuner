# 侧栏工作台（Sidebar Studio）

DSH 左侧栏插件：管理左侧栏入口的显隐，并用两条横条调整入口区与底部动作区的高度。所有偏好只保存在本机。

## 功能

1. **入口显隐** —— 在「侧栏工作台」面板（或左侧栏「更多」菜单）里开关每个入口。被隐藏的入口仍可从「更多」菜单打开；「插件」入口由宿主固定显示，藏不掉。
2. **两条横条** ——
   - 上横条骑在「面板入口区」下沿：向下拖入口区变高。
   - 下横条骑在「底部动作区」上沿：向上拖底部动作区变高。
   - 双击横条或点面板里的「恢复自动」交回宿主的自动高度；键盘 `↑`/`↓` 微调、`Home`/`End` 复位。
3. **不碰宿主原装区** —— 顶部品牌行、新会话按钮、底部头像行（`settingsArea`）、`footArea` 本身，本插件一个样式都不写。整栏宽度仍由宿主自带的右边缘拖拽控制。

## 偏好

- 键：`dsh-sidebar-studio:prefs:v2`，`schema = 3`。
- 读到 schema 不一致时**丢弃高度、只保留入口显隐**，避免旧版高度把入口区钉死。
- `navHeight` / `footerHeight`：`null` = 自动，`0` = 主动压到 0，正数 = 自定义像素。

## 结构

- `client.js` —— 全部逻辑（显隐通道 + 两条横条 + 面板 UI），客户端 bundle。
- `index.js` —— 宿主侧空 `apply()`（无宿主服务）。
- `cordis.patch.yml` —— 注册 bundle。
- `locale/zh.json` / `locale/en.json` —— 插件名与描述。
