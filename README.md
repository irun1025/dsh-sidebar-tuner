# 左侧栏优化（Left Sidebar Tuner）

> **本项目由 vibe coding 完成。** 从第一个字符到最终发布，代码、调试与文档全部在 AI 协作下迭代产生，没有逐行手写的阶段。使用前请知悉这一点：它按实际需要工作，但不保证符合传统工程评审的标准。

DSH 左侧栏插件：管理左侧栏入口的显隐，并用两条横条调整入口区与底部动作区的高度。所有偏好只保存在本机。

## 功能

1. **入口显隐** —— 在「左侧栏优化」面板（或左侧栏「更多」菜单）里开关每个入口。被隐藏的入口仍可从「更多」菜单打开；「插件」入口由宿主固定显示，藏不掉。
2. **两条横条** ——
   - 上横条骑在「面板入口区」下沿：向下拖入口区变高。
   - 下横条骑在「底部动作区」上沿：向上拖底部动作区变高。
   - 双击横条或点面板里的「恢复自动」交回宿主的自动高度；键盘 `↑`/`↓` 微调、`Home`/`End` 复位。
3. **不碰宿主原装区** —— 顶部品牌行、新会话按钮、底部头像行（`settingsArea`）、`footArea` 本身，本插件一个样式都不写。整栏宽度仍由宿主自带的右边缘拖拽控制。

## 安装

```bash
dsh plugin add dsh-sidebar-tuner
```

装完刷新页面即可生效。也可以在 DSH 的插件面板里从市场搜索「左侧栏优化」。

## 偏好

- 键：`dsh-sidebar-tuner:prefs:v2`，`schema = 3`。
- 从旧包 `dsh-sidebar-studio` 升级时，会自动把旧键 `dsh-sidebar-studio:prefs:v2` 的值迁移过来并删除旧键，已有设置不丢。
- 读到 schema 不一致时**丢弃高度、只保留入口显隐**，避免旧版高度把入口区钉死。
- `navHeight` / `footerHeight`：`null` = 自动，`0` = 主动压到 0，正数 = 自定义像素。

## 结构

- `client.js` —— 全部逻辑（显隐通道 + 两条横条 + 面板 UI），客户端 bundle。
- `index.js` —— 宿主侧空 `apply()`（无宿主服务）。
- `cordis.patch.yml` —— 注册 bundle。
- `locale/zh.json` / `locale/en.json` —— 插件名与描述。

## 兼容性

`engines.dsh`：`>=0.2.0-rc.2 <0.3.0-0`。入口显隐依赖宿主暴露的 pin 通道；宿主若不提供，本节开关会提示「不会生效」，高度调整仍可用。
